# Address-Book
This is a console-based Address Book application written in C, allowing users to add, delete, search, and update contacts with names, phone numbers, and email addresses.
# Features

- **Add Contacts**: Store names, phone numbers, and email addresses.
- **Delete Contacts**: Remove contacts from the address book.
- **Search Contacts**: Look up contacts by name.
- **Update Contacts**: Modify phone numbers and email addresses.
- **File Operations**: Persist contact data in a file for reuse.

## Technologies Used

- **C Programming Language**
- **File Handling** for data persistence
- **Standard Input/Output**
